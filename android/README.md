# Планировщик задач для Android

Нативное Android-приложение на Kotlin и Jetpack Compose. Задачи хранятся локально
в SQLite и не отправляются в сеть.

## Возможности

- активные задачи и постоянная зона «Фокус»;
- произвольная сортировка карточек и перенос между списками долгим нажатием;
- создание и редактирование нажатием на карточку;
- необязательные дедлайн, важность и описание;
- красные ближайшие и просроченные дедлайны;
- недельный список с переключением недель;
- архив завершённых задач;
- постоянная тёмная тема.

Порядок карточек хранится в `SharedPreferences`, а сами задачи — в SQLite.
Приложение не создаёт фоновых сервисов и постоянных уведомлений.

## Запуск в Android Studio

1. Откройте папку `android` как отдельный проект.
2. Дождитесь Gradle Sync и установки Android SDK 37.0.
3. Выберите телефон или эмулятор и нажмите **Run**.

Минимальная версия системы — Android 8.0 (API 26).

## Сборка из терминала

Требуются JDK 17+ и Android SDK 37.0:

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
